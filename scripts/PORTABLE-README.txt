Vocabulary Web Portable

1. Double-click start-portable.bat.
2. Keep the command window open while using the website.
3. The browser opens http://127.0.0.1:4173 automatically.
4. Close the command window to stop the website.

To move learning data:
- On the old computer, open Dashboard > Data Migration > Export Backup.
- Copy the exported JSON file to the new computer.
- On the new computer, open Dashboard > Data Migration > Import Backup.

The portable package runs on Windows PowerShell and does not require Node.js.
